  🎯 为什么关机也能运行？

  1. GitHub Actions 在云端运行

  GitHub Actions 运行在 GitHub 的服务器上
  ├─ 不依赖主人的电脑
  ├─ 不需要主人保持开机
  └─ 完全自动化的云服务

  2. 定时任务如何触发

  # 在 GitHub 服务器上
  schedule:
    - cron: '30 22 * * *'  # 每天 UTC 22:30

  # UTC 22:30 = 北京时间 6:30（第二天）

  工作流程：
  1. 🕚 北京时间每天 6:30（实际上是前一天的22:30 UTC）
  2. 🤖 GitHub 服务器自动触发工作流
  3. 📊 运行 scripts/finance_digest.py 抓取数据
  4. 🤖 调用智谱AI生成简报
  5. 📱 调用 PushPlus API 推送到微信
  6. ✅ 所有步骤都在云端完成
