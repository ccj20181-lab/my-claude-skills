公文/办公最核心的“四大金刚”字体（强烈推荐一次性装齐）
这些是跨平台（尤其是 macOS + Windows + WPS/Word 互传）最容易出问题的字体：

仿宋_GB2312（或叫 FangSong_GB2312 / 仿宋国标）
→ 公文正文标准字体（3号），几乎所有体制内公文都用这个。macOS 默认没有，必须装。
仿宋（Windows 7 后自带的仿宋，非_GB2312 版）
→ 字符更多、更美观，很多新文档会优先用这个。建议两个都装，兼容性最好。
方正小标宋简体（FZXiaoBiaoSong-B01S 或类似）
→ 红头文件标题（2号小标宋体）、发文机关标识专用。Word 经常认成“方正小标宋”或“标宋”。
楷体_GB2312（或 KaiTi_GB2312 / 楷体国标）
→ 公文层次序号第二层常用（（一）这种），也常用于落款、附件说明。

其他高频办公/公文补充字体（按使用频率排序，建议都装上）

宋体（SimSun） / 中易宋体 → 正文备选、落款、表格常用
黑体（SimHei） / 中易黑体 → 一级标题、强调、结构层次第一层（“一、”这种）
华文仿宋（STFangSong） → macOS 自带，接近但不完全等同仿宋_GB2312
华文楷体（STKaiti） → macOS 自带楷体
华文宋体（STSong） → macOS 自带宋体
微软雅黑（Microsoft YaHei） → 现代文档、PPT、网页常用（非公文强制，但超常见）
等线（DengXian） / 思源黑体 → Office 2016+ 新默认（部分场景替换黑体）
隶书（LiSu）、幼圆（YouYuan） → 偶尔出现在老文档标题或装饰

一次性下载推荐方式（macOS 用户）
直接搜索下载下面这些关键词的字体包，通常是一个 zip 包含以上全部或绝大部分：

“Windows 常用中文字体包 simsun simhei simfang simkai”
“公文常用字体包 方正小标宋 仿宋_GB2312 楷体_GB2312”
“学校/机关公文字体包 zip” （很多高校官网有分享，如山财大、浙师大等提供的字体包）
GitHub 搜索 “MacFonts” 或 “Chinese Fonts for Mac” 项目，常有完整集合

最全的一键包建议（搜索这些就能找到很多网盘/官网直链）：

“常用办公字体（字库）.zip” （包含方正小标宋 + 仿宋_GB2312 + 楷体_GB2312 等）
“Windows 公文字体合集 sim* 系列”

下载后：

解压得到 .ttf / .ttc / .otf 文件
macOS 上双击每个文件 → 「字体册」自动打开 → 点击“安装字体”（建议选“所有用户”）
如果 Word / WPS 仍不认 → 把字体文件额外复制到 /Applications/Microsoft Word.app/Contents/Resources/DFonts 或类似路径（重启软件）

装完后基本能完美兼容 99% 的公文/Word 文档，不会再乱码或变黑体/苹方了。
