# 视觉风格指南

基于参考视频「活出硬核态度.mp4」的风格分析

## 整体风格
- **风格类型**: 极简手绘简笔画（Minimalist Doodle）
- **视觉感受**: 类似儿童涂鸦 / 表情包的随意感

## 配色方案
| 元素 | 颜色值 | 说明 |
|------|--------|------|
| 背景 | `#FFFFFF` | 纯白色 |
| 线条/文字 | `#000000` | 纯黑色 |
| 强调色 | `#000000` | 无彩色强调 |
| 次要文字 | `#333333` | 深灰色 |

## 人物设计
- **头部**: 圆形，无面部细节
- **身体**: 简单线条组成的火柴人
- **情绪表达**: 用符号代替表情
  - 问号 `?` 表示困惑
  - 感叹号 `!` 表示惊讶
  - 井号 `#` 表示复杂情绪
  - 星星 `★` 表示开心/重视

## 线条特点
- **粗细**: 1-2px 细线条
- **风格**: 有手绘的随意感和轻微抖动
- **连接**: 线条端点圆润

## 场景构成
- **背景**: 纯白，无任何装饰
- **留白**: 大量留白，元素居中
- **层次**: 单层平面，无阴影无深度
- **元素数量**: 每个场景 1-3 个元素

## 文字排版
- **字体**: 手写体风格（中文用 PingFang SC）
- **对齐**: 居中对齐
- **位置**: 通常位于画面底部
- **大小**: 适中，不喧宾夺主

## 动画原则
- **入场**: 简单淡入 + 缩放
- **转场**: 淡入淡出为主
- **节奏**: 缓慢舒适，不急不躁
- **循环**: 避免无限循环动画

## 图片生成提示词模板
```
极简手绘简笔画风格：
- 纯白色背景(#FFFFFF)
- 黑色细线条(1-2px)
- 简笔人物：圆形头部 + 线条身体
- 用符号表达情绪
- 手绘随意感，轻微抖动
- 大量留白，居中构图

场景内容：[具体描述]
```
