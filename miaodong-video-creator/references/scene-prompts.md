# 财经场景图片提示词库

本文档提供财经视频场景图片的提示词参考，用于生成风格一致的 3:4 竖屏场景图。

## 通用原则

1. **始终强调 3:4 竖屏**：每个提示词都应包含 "3:4竖屏构图" 或 "适合手机观看"
2. **保持风格一致**：同一视频的所有场景应使用相同的风格关键词
3. **简洁清晰**：避免过于复杂的背景，确保文字可以清晰叠加
4. **品牌色彩**：推荐使用深蓝色 (#1a1a2e)、金色 (#ffd700)、科技紫 (#6c5ce7)

## 注意事项

1. **避免文字**：提示词中不要要求生成具体文字，文字由 Remotion 代码叠加
2. **预留空间**：确保背景有足够的留白或低对比度区域用于叠加文字
3. **保持一致**：同一视频的所有场景应使用相似的色调和风格
4. **测试迭代**：生成后检查效果，必要时调整提示词重新生成
