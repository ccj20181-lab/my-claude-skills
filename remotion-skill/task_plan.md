# Task Plan: Remotion 视频效果全面优化（字幕化 + 素材强化 + 形象替换 + 动画升级）

## Goal
生成的视频在视觉表达上更“视频化”：不再出现重复文案框；文案以更美观的字幕系统呈现；素材图标更大且更频繁；移除火柴人体系，替换为简洁人物形象；动画与转场更丰富且稳定可控。

## Phases
- [x] Phase 1: 现状审计与问题复现（定位重复框/素材小/动画弱的根因）
- [x] Phase 2: 数据结构与渲染层设计（字幕体系、素材体系、人物形象、动画规范）
- [x] Phase 3: 实施（Remotion 组件重构 + Python 数据注入/素材拷贝改造）
- [x] Phase 4: 端到端验证与回归（生成样例视频、检查音轨/素材/字幕/性能）
- [ ] Phase 5: 文档与使用方式更新（SKILL.md/notes，给出推荐参数与约束）

## Acceptance Criteria
- [ ] 同一场景不再出现“上下两个文案框”重复（只保留一种文案呈现：字幕体系）
- [ ] 字幕样式更美观：两行内自适应、可读性强、与背景对比稳定
- [ ] 每个场景至少出现 1 个主素材（icon hero），并有 2-4 个辅助素材（icon cloud）
- [ ] 主素材尺寸明显提升（移动端一眼可见）
- [ ] 火柴人组件不再出现在最终视频中；用简洁人物形象（SVG/矢量）替代
- [ ] 动画更丰富：入场、呼吸/漂浮、强调标注（手绘线条）、更好的转场
- [ ] 渲染稳定：`python3 scripts/main.py ...` 端到端可产出带声画的 mp4

## Key Questions
1. 字幕体系：无 word timestamps 时，如何让字幕出现/消失节奏不突兀？
2. 素材体系：不依赖目录遍历的情况下，如何保证多素材可用且可控？
3. 人物形象：用纯 SVG 生成，如何做到“可爱但不花哨”，并与场景情绪绑定？
4. 动画：如何在 Remotion 中保证动画可控、不过度耗时渲染？

## Decisions Made
- 文案只保留“字幕层”，移除 `TextBubble` 在正文场景中的默认使用，避免重复。
- 素材采用 “hero icon + icon cloud” 模式：hero 更大，cloud 低透明度做气氛。
- 人物形象用纯 SVG（HostAvatar），以 `character.type` 映射表情/姿态；不再依赖 `assets/characters/`。
- 动画遵循：少而关键（入场、强调、轻微呼吸），避免高成本滤镜/复杂路径。
