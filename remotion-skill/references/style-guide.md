# 视觉风格指南

本文档定义秒懂金融视频的视觉设计规范。

## 整体风格

### 设计理念
- **白板手绘风格**: 模拟在白板上讲解的感觉，亲切自然
- **简洁清晰**: 减少视觉干扰，突出核心内容
- **温暖友好**: 色彩柔和，给人舒适感

### 视频规格
| 属性 | 值 |
|------|-----|
| 分辨率 | 1080 × 1440 (3:4) |
| 帧率 | 30 FPS |
| 格式 | MP4 (H.264) |
| 平台 | 小红书优化 |

---

## 色彩系统

### 主色调
```
背景色: #FCFCFA (温暖的白色)
文字主色: #1A202C (深灰)
文字辅色: #4A5568 (中灰)
```

### 强调色（按场景类型）
| 场景类型 | 强调色 | 用途 |
|---------|--------|------|
| hook | #FF6B35 (橙色) | 吸引注意 |
| question | #E53E3E (红色) | 引发思考 |
| explain | #3182CE (蓝色) | 专业讲解 |
| analogy | #38A169 (绿色) | 生活类比 |
| example | #D69E2E (黄色) | 案例说明 |
| comparison | #805AD5 (紫色) | 对比分析 |
| summary | #2B6CB0 (深蓝) | 总结要点 |
| cta | #D53F8C (粉色) | 行动引导 |

### 使用原则
1. 每个场景使用对应的强调色作为装饰元素
2. 文字始终使用主色/辅色，保持可读性
3. 强调色用于边框、圆点、图标等装饰

## 布局规范

### 安全区域
```
左右边距: 60px
上下边距: 80px
```

### 固定元素位置
```
Logo: 右上角 (top: 40px, right: 40px, width: 120px)
水印: 右下角 (bottom: 40px, right: 40px)
```

### 内容区域
- 标题场景: 垂直居中偏上 (35%)
- 解释场景: 文字在上方，角色在下方
- 问题场景: 文字居中，角色在左下

## 火柴人设计

### 基本形态
- 圆形头部 (直径约 50px 相对单位)
- 简笔线条身体
- 线条粗细: 4px
- 颜色: #2D3748 (深灰)

### 表情类型
| 类型 | 描述 | 使用场景 |
|------|------|----------|
| neutral | 平静表情 | 默认/标题 |
| happy | 微笑 | 总结/理解 |
| confused | 困惑（头上问号） | Hook/问题 |
| thinking | 思考 | 问题/分析 |
| surprised | 惊讶（张嘴） | 案例/数据 |
| pointing | 指示（手指向右） | 解释/讲解 |
| waving | 招手 | 开场/结尾 |

### 动画效果
- 入场: 从下方滑入 + 弹性缓动
- 待机: 轻微上下浮动 (幅度 5px, 周期 0.5s)
- 表情切换: 0.3s 淡入淡出

## 文字气泡设计

### 样式
```css
background: #FFFFFF;
border-radius: 24px;
border: 3px solid [场景强调色];
box-shadow: 0 4px 20px rgba(0, 0, 0, 0.08);
padding: 40px;
```

### 装饰元素
- 左上角圆点: 直径 16px, 使用场景强调色
- 可选: 手绘风格下划线效果

### 文字动画
- 打字机效果: 每秒显示 15-20 个字符
- 光标闪烁: 显示中时在末尾闪烁

---

## 转场效果

### 推荐转场
1. **淡入淡出** (默认): 0.5s 透明度过渡
2. **滑入**: 从右侧滑入，配合弹性缓动
3. **缩放**: 从 0.9 放大到 1.0

### 转场时长
- 场景内: 10-15 帧 (0.33-0.5s)
- 场景间: 15-20 帧 (0.5-0.67s)

---

## 手绘效果

### SVG 描边动画
用于强调关键词或绘制装饰元素。

**下划线**
```svg
<path d="M 5 15 Q 50 10 100 15 Q 150 20 195 12"
      stroke="[color]"
      stroke-width="4"
      stroke-dasharray="200"
      stroke-dashoffset="[animated 200→0]" />
```

**圈选**
```svg
<ellipse cx="60" cy="60" rx="50" ry="45"
         stroke="[color]"
         stroke-width="4"
         transform="rotate(-10)"
         stroke-dasharray="320"
         stroke-dashoffset="[animated 320→0]" />
```

### 动画时长
- 下划线: 0.5s
- 圈选: 0.7s
- 箭头: 0.4s

## 响应式考虑

虽然目标平台是小红书（固定 3:4），但设计时考虑:

1. **核心内容居中**: 确保主要内容在中间 60% 区域
2. **边缘留白**: 为平台 UI 覆盖预留空间
3. **字号适中**: 在手机端也能清晰阅读
