# SWOT分析报告生成器

## 概述

本Skill专门用于生成企业SWOT（优势-劣势-机遇-挑战）分析报告。核心特点：

1. **主动调研**：不仅依赖用户输入，还会通过互联网广泛搜索、调研相关信息
2. **多维分析**：收集企业信息、行业环境、政策环境、宏观环境等多维度信息
3. **并行处理**：使用多个子代理并行执行调研任务，由主代理综合分析
4. **规范输出**：生成格式规范的Word文档报告，篇幅与专业咨询报告看齐

## 触发方式

- 显式调用：`/swot` 或 `/swot-analysis`
- 关键词触发：当用户提到"SWOT分析"、"战略分析"、"优劣势分析"、"机遇挑战分析"等

| 信息类型 | 说明 | 来源 |
|----------|------|------|

| 信用评级报告 | 第三方机构出具的信用评级报告 | 用户提供/评级机构官网 |

| 高管信息 | 管理团队背景、变动情况 | 网络搜索 |

| 信息类型 | 说明 | 调研重点 |
|----------|------|----------|
| 行业概况 | 行业规模、发展阶段、增长趋势 | 市场规模、增速、生命周期 |

### 三、政策环境信息

| 信息类型 | 说明 | 调研重点 |
|----------|------|----------|

### 四、宏观环境信息

| 信息类型 | 说明 | 调研重点 |
|----------|------|----------|

| 社会趋势 | 人口结构、消费习惯、社会变迁 | 需求变化、社会风险 |
| 技术变革 | 重大技术突破、数字化转型 | 颠覆性技术、效率提升 |
| 环境约束 | 环保政策、碳中和、ESG | 绿色转型、合规要求 |

## 工作流程

### Phase 1: 信息收集（并行调研）

**必须使用Task工具启动多个子代理并行执行调研任务！**

```
┌─────────────────────────────────────────────────────────────┐
│                      主代理（协调者）                          │
│                         ↓ 分发任务                            │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│ 子代理1  │ 子代理2  │ 子代理3  │ 子代理4  │    子代理5      │
│ 企业信息 │ 行业环境 │ 政策环境 │ 宏观环境 │  竞争对手分析   │
│  调研    │  调研    │  调研    │  调研    │      调研       │
└──────────┴──────────┴──────────┴──────────┴─────────────────┘
                         ↓ 汇总结果
              主代理综合分析 → SWOT要素识别
```

### Phase 2: 信息整合与分析

主代理收集各子代理的调研结果后，进行：

1. **信息交叉验证**：比对不同来源的信息，确保准确性
2. **关键信息提取**：识别对SWOT分析有价值的关键点
3. **信息优先级排序**：按重要性和相关性排序

### Phase 3: SWOT要素识别

基于收集的全部信息，识别SWOT要素（每项要详细展开，包含数据和事实支撑）：

| 类别 | 数量 | 要求 |
|------|------|------|
| 优势（S） | 5-6项 | 每项100-150字，包含具体数据、案例支撑 |
| 劣势（W） | 5-6项 | 每项100-150字，深入分析问题和根因 |
| 机遇（O） | 4-5项 | 每项100-150字，结合政策文件、市场数据 |
| 挑战（T） | 3-4项 | 每项100-150字，分析风险来源和影响 |

### Phase 4: 战略分析（关键！）

**第五节：战略定位矩阵分析**
- 外部环境判断：机遇 vs 挑战（O > T 或 T > O）
- 内部环境判断：优势 vs 劣势（S > W 或 W > S）
- 战略态势结论：增长型/防御型/扭转型/多元化

**第六节：战略开发矩阵分析**
- SO战略（增长型）：发挥优势抓住机遇
- WO战略（扭转型）：利用机遇克服劣势
- ST战略（多元化）：利用优势应对挑战
- WT战略（防御型）：减少劣势规避挑战

每种战略需要给出具体的战略举措（2-3条）

### Phase 5: 内容撰写

按照规范格式撰写各项分析，确保篇幅充实、数据详实：

```
{编号}-{标题}。{详细分析内容，包含数据支撑、案例说明、原因分析}。
```

### Phase 6: 生成Word文档

使用 `scripts/create_swot_doc.js` 脚本生成格式规范的Word文档。

## SWOT分析方法论

### 优势（Strengths）分析维度

内部积极因素，企业可控的优势资源：

1. **资源优势**：资金、资产、牌照，自然资源等
2. **能力优势**：技术、研发、生产、营销等核心能力
3. **市场优势**：品牌、客户、渠道、市场份额等
4. **组织优势**：管理团队、人才储备、企业文化等
5. **政策优势**：政府支持、政策红利、行业地位等
6. **协同优势**：产业链整合、生态布局等

### 劣势（Weaknesses）分析维度

内部消极因素，需要改进的方面：

1. **资源劣势**：资金短缺、资产质量差等
2. **能力短板**：技术落后、管理不足等
3. **市场劣势**：品牌弱、客户流失、渠道不足等
4. **组织问题**：人才流失、机制僵化等
5. **历史包袱**：债务、诉讼、不良资产等
6. **协同不足**：内部内耗、资源分散等

### 机遇（Opportunities）分析维度

外部积极因素，可利用的发展机会：

1. **政策机遇**：国家战略、产业政策、区域发展等
2. **市场机遇**：需求增长、新市场开拓等
3. **技术机遇**：技术变革、数字化转型等
4. **行业机遇**：行业整合、国产替代等
5. **合作机遇**：战略合作、并购机会等

### 挑战（Threats）分析维度

外部消极因素，需要应对的风险：

1. **宏观风险**：经济周期、国际形势等
2. **政策风险**：监管趋严、政策调整等
3. **行业风险**：竞争加剧、行业衰退等
4. **市场风险**：需求变化、价格波动等

## 战略分析框架（第五、六节）

### 第五节：战略定位矩阵分析

#### 1. 战略定位诊断

**外部环境判断**：
- 分析机遇(O)与挑战(T)的对比关系
- 判断外部环境是"机遇大于挑战"还是"挑战大于机遇"

**内部环境判断**：
- 分析优势(S)与劣势(W)的对比关系
- 判断内部环境是"优势大于劣势"还是"劣势大于优势"

#### 2. 战略定位结论

根据SWOT战略区间，确定四种战略态势之一：

| 态势 | 内部 | 外部 | 战略类型 |
|------|------|------|----------|
| 增长型 | S > W | O > T | SO战略 - 进攻型 |
| 扭转型 | W > S | O > T | WO战略 - 抓住机遇弥补短板 |
| 多元化 | S > W | T > O | ST战略 - 利用优势应对威胁 |
| 防御型 | W > S | T > O | WT战略 - 收缩防守 |

### 第六节：战略开发矩阵分析

#### 1. 主导战略 (WO-扭转型)

利用机遇克服劣势的战略组合，需要给出2-3条具体战略举措。

#### 2. 辅助战略 (SO-增长型)

发挥优势抓住机遇的战略组合，需要给出2-3条具体战略举措。

#### 3. 保障战略 (ST-多元化)

利用优势应对挑战的战略组合，需要给出2-3条具体战略举措。

#### 4. 底线战略 (WT-防御型)

减少劣势规避挑战的战略组合，需要给出2-3条具体战略举措。

## 关键执行规则

### ⚠️ 必须遵守

1. **必须并行调研**：使用Task工具启动多个Explore子代理并行执行调研任务
2. **多维度收集**：确保覆盖企业、行业、政策、宏观四个维度
3. **信息验证**：交叉验证不同来源的信息，确保准确性
4. **时效性**：优先获取最新信息，注意信息的时间范围
5. **数据支撑**：分析内容应包含具体数据和事实支撑
6. **篇幅要求**：每个SWOT要素100-150字，确保分析有深度
7. **完整结构**：必须包含第五节战略定位分析和第六节战略开发矩阵

### 调研子代理数量建议

| 情况 | 子代理数量 | 说明 |
|------|------------|------|
| 简单分析 | 3个 | 企业信息+行业环境+政策环境 |
| 标准分析 | 5个 | 完整五个维度调研 |
| 深度分析 | 6-8个 | 增加专项调研（如财务、技术、竞争对手等） |
