## 二、问题诊断：Exit Code 137 详解

### 什么是 Exit Code 137？
- **含义**：进程被操作系统强制终止（OOM Killer）
- **原因**：内存耗尽（Out Of Memory）
- **触发机制**：Linux/macOS 内核检测到进程占用过多内存，主动杀死进程保护系统

### 为什么批量模式会 OOM？

| 风险点 | 分析 |
|-------|------|
| **同时加载多张参考图** | batch_generate.py 会预加载所有参考图到内存（base64编码后占用约10MB+/张） |
| **多图并行处理** | 4K分辨率图片生成需要大量GPU内存 + 系统内存 |
| **Prompt长度** | 带参考图的prompt非常大，API请求体膨胀 |
| **Python内存管理** | 脚本在循环中累积内存碎片 |

## 三、优化方案对比

### 方案A：批量模式（失败）
```bash
python batch_generate.py md1.md md2.md -r 4K
```
- **优点**：一次命令生成全部
- **缺点**：内存压力大，易OOM

### 方案B：逐张生成（成功）✅ 推荐
```bash
python generate_one_by_one.py md1.md -r 4K
python generate_one_by_one.py md2.md -r 4K
```
- **优点**：每张图独立内存空间，稳定性高
- **缺点**：需要多次执行命令
