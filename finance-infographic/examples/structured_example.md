# 结构化文案示例 - 智谱AI上市

本文档展示如何使用 `--titles` 参数为结构化文案生成多张信息图。

## 核心结构

财经文案通常采用"是什么 → 为什么 → 怎么办"的三段式结构：

1. **是什么**：介绍主体、背景、基本信息
2. **为什么**：分析原因、意义、影响
3. **怎么办**：提供建议、方法、注意事项

## 文件拆分

### 第1张图：是什么.md

```markdown
# 智谱AI是谁？

**智谱AI是谁？**

说白了，智谱AI就是从清华大学实验室里"孵化"出来的AI公司。

它的技术源头，是清华大学计算机系的知识工程实验室（KEG）——这个实验室1996年就成立了，是国内最早搞自然语言处理、知识图谱的老牌科研机构。

**创始班底星光熠熠：**

• CEO张鹏：清华博士，2002年就在KEG实验室搞研发，一干就是二十多年

• 首席科学家唐杰：清华计算机系教授、系副主任，国家杰出青年基金获得者

• 董事长刘德兵：中科院博士，师从中国工程院院士高文

智谱最出圈的产品，就是GLM系列大模型和ChatGLM对话机器人——你可以把它理解成"中国版的GPT"。
```

### 第2张图：为什么.md

```markdown
# 为什么成为第一个

**第一，钱够烧，但也该"见回头钱"了**

据招股书披露，智谱成立6年，已经完成8轮融资，累计拿了83亿元。投资方阵容堪称豪华：美团、阿里、腾讯、蚂蚁、小米、红杉、高瓴、启明……

但问题是，大模型这玩意儿太烧钱了。智谱2024年研发费用就花了将近22亿元，虽然营收增长很快（同比涨了130%），但离盈利还有一段距离。

**第二，赶上了好时候**

2025年港股IPO市场火得一塌糊涂，今年募资额已经突破340亿美元，同比暴涨200%多。资本市场对AI的热情正处于巅峰。

**第三，抢占"第一股"的头衔**

在资本市场，"第一"这两个字值多少钱？答案是：非常值钱。第一个吃螃蟹的人，往往能享受最高的估值溢价和最大的市场关注度。
```

### 第3张图：怎么办.md

```markdown
# 普通人怎么参与

**招股书关键数据**

• IPO前估值：243.8亿元（约34亿美元）
• 2024年营收：约3亿元，同比增长130%
• 毛利率：50%+
• 研发团队占比：74%（657人）

**参与方式**

(1) 港股打新：如果智谱成功上市，有港股账户的朋友可以直接参与。但要注意，科技股上市首日波动往往很大。

(2) 关注A股概念股：智谱的投资方里，腾讯、阿里、美团这些都是上市公司。

(3) 关注后续的"AI上市潮"：智谱只是开了个头，后面MiniMax、月之暗面、百川智能这些"AI六小龙"，大概率也会陆续跟进。

**风险提示**

• 大模型公司普遍还在"烧钱换规模"的阶段，盈利时间表不确定
• 估值是否合理？市场情绪退潮后会不会"杀估值"？
```

## 生成结果

生成的3张图片将具有以下特点：

### 固定元素（完全一致）
- ✅ 右上角logo：位置、大小、样式一致
- ✅ 右下角秒懂金融标记：位置、大小、样式一致
- ✅ 整体布局：内容板块排列、间距、比例一致

### 可变元素（根据内容调整）
- 主标题：第1张"是什么"、第2张"为什么"、第3张"怎么办"
- 正文内容：从对应的md文件中逐字提取
- 视觉元素：根据内容生成相关的图标、图表

## 最佳实践

1. **主标题长度**：建议2-5个字，简洁明确
2. **检查清单**：
   - [ ] 每张图都有右上角logo
   - [ ] 边框样式完全一致
   - [ ] 主标题格式一致（字号64px）
   - [ ] 主标题文字符合预期（是什么/为什么/怎么办）

### 示例3：问题-解决方案结构

```markdown
(2) 步骤2
(3) 步骤3

### 方案二
(1) 步骤1
(2) 步骤2
(3) 步骤3

## 预期效果

- 改善一：具体说明
- 改善二：具体说明
- 改善三：具体说明
```

**信息密度提升技巧：**
1. 使用数字和具体数据
2. 增加对比项（同比、环比、横向对比）
3. 使用列表 (1)(2) 或 - 组织要点
4. 适当使用子标题 ## 分段
5. 每段控制在3-5个要点，避免过载
