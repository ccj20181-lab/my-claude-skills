## ⚡ 随机生成三步法

### 第1步：投骰子选类型
```
掷骰子（1-9）→ 确定故事类型

1️⃣ 逆袭类：笔试靠后，面试大翻盘
2️⃣ 第一名类：笔试/面试/总分第一
3️⃣ 守擂类：笔试靠前，面试成功守住
4️⃣ 压线上岸类：刚好卡在招聘人数边缘
5️⃣ 特殊身份类：在职/宝妈/怀孕/跨专业/大龄
6️⃣ 押中原题类：考题与材料高度契合
7️⃣ 多战上岸类：二战/三战/多年备考
8️⃣ 组团上岸类：夫妻/闺蜜/同学一起
9️⃣ 短期突击类：考前极短时间准备
```

### 第2步：抽卡片选地区
```
抽卡片（1-10）→ 确定城市 → 再随机选区

🏙️ 城市池：
1. 厦门（思明/湖里/集美/海沧/同安/翔安）
2. 长沙（芙蓉/天心/岳麓/开福/雨花/望城）
3. 成都（锦江/青羊/金牛/武侯/成华/龙泉驿）
4. 杭州（上城/拱墅/西湖/滨江/萧山/余杭）
5. 深圳（福田/南山/罗湖/宝安/龙岗/龙华）
6. 佛山（禅城/南海/顺德/三水/高明）
7. 东莞（莞城/南城/东城/松山湖/虎门/长安）
8. 苏州（姑苏/吴中/相城/高新/工业园区）
9. 重庆（渝中/江北/南岸/沙坪坝/九龙坡/渝北）
10. 武汉（江岸/江汉/硚口/汉阳/武昌/洪山）
```

### 第3步：滚轮盘填数据
```
根据故事类型随机生成数据

【逆袭类】笔试: 8-80 → 面试: 1-15 → 分数: 82-89
【第一名】分数: 88-92 → 差距: 0.5-3分
【守擂类】笔试: 1-7 → 面试: 1-8 → 压力描述
【压线类】招聘人数 → 排名=人数±2 → 差距: 0.03-1分
【特殊身份】身份标签 → 困难时长: 半年-五年
【押中题】题目: 1-3个 → 主题随机 → 使用材料
【多战类】失败: 1-5次 → 跨度: 2-5年
【组团类】关系 → 上岸情况
【短期类】时长: 3天-2周 → 学习强度
```
