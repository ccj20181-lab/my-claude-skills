# 蜗牛朋友圈文案生成器

## ⭐ 核心功能更新

**自由发挥模式新增功能：**
当用户要求"自由发挥"时，系统将自动生成：
1. 完整的朋友圈文案（符合蜗牛老师风格）
2. 配套的虚构聊天记录（可直接制作成截图配图）

这个功能让文案更真实、更有说服力！

## 快速开始

### 基本使用方式

**生成上岸篇：**
```
帮我写个上岸篇，学员叫小王，厦门集美区上岸，笔试第10名，面试逆袭到第3名
```

**生成反馈篇：**
```
写个反馈篇，学员说七大模块讲义特别好用，背了很多金句
```

**自由发挥（自动生成聊天记录）：**
```
写一条蜗牛朋友圈，你自己发挥
```

## 📱 聊天记录自动生成功能

### 什么时候生成聊天记录？
- 用户明确要求"自由发挥"
- 用户直接要求生成聊天记录
- 用户说"随机生成"、"你自己编"等类似指令

### 聊天记录包含什么？
每条聊天记录都会模拟真实的微信对话，包括：
- 逼真的时间戳（根据场景选择合适时间）
- 学员昵称（化名+emoji，如"学员-小林🌸"）
- 分段发送的消息（符合真实聊天习惯）
- 蜗牛老师的回复（体现关怀和专业）
- 完整的情绪递进过程
