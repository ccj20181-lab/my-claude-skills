# 蜗牛朋友圈文案生成器

## 快速开始

### 基本使用方式

**生成上岸篇：**
```
帮我写个上岸篇，学员叫小王，厦门集美区上岸，笔试第10名，面试逆袭到第3名
```

**生成反馈篇：**
```
写个反馈篇，学员说七大模块讲义特别好用，背了很多金句
```

## 核心工作流程

### 第一步：识别文案类型

根据用户需求自动判断：
- **上岸篇**：学员考上教师编制、报喜、分享上岸经验
- **反馈篇**：学员购买课程/讲义后的好评、学习感受

### 第二步：收集必要信息

#### 🎲 随机生成模式（用户未提供具体信息时）

**⚠️ 核心原则：杜绝模板化，确保每次生成都有足够的随机性和多样性！**

当用户要求"随机生成"或"自由发挥"时，必须：

1. **读取随机元素库**：
```bash
读取 config/random-elements.md
```

2. **随机选择故事类型**（从9种类型中随机选1种）：
   - 类型1: 逆袭类
   - 类型2: 第一名类
   - 类型3: 守擂类
   - 类型4: 压线上岸类
   - 类型5: 特殊身份类（在职/宝妈/跨专业等）
   - 类型6: 押中原题类
   - 类型7: 多次失败后上岸类
   - 类型8: 夫妻/闺蜜/同学组团类
   - 类型9: 短期突击奇迹类

3. **随机选择地区**（从10个热门城市中随机选1个，再随机选区）

4. **随机生成数据**（根据故事类型生成合理的排名、分数、人数等）

5. **随机选择学员评价**（从对应维度中随机选2-3条）

6. **随机选择聊天风格和时间场景**

**🚫 严禁行为**：
- ❌ 每次都用"逆袭类"故事
- ❌ 固定使用某个地区（如"长沙雨花区"）
- ❌ 固定使用某组数字（如"笔试第12，面试第5"）
- ❌ 重复使用相同金句（如"赏识教育是孩子生命中的一道阳光"）
- ❌ 聊天时间总是19:35
- ❌ 学员昵称总是"小雨🌸"

#### 📝 用户提供具体信息模式

**上岸篇所需信息：**
- 地区（必需）：如"厦门集美区"、"长沙"、"佛山"
- 成绩数据（推荐）：
  - 笔试排名/分数
  - 面试排名/分数
  - 总分排名
  - 逆袭名次（如果有）
- 亮点（可选）：
  - 押中原题
  - 第一名上岸
  - 备考故事（二战、在职、宝妈等）
- 学员评价（可选）：学员说的原话

**反馈篇所需信息：**
- 产品类型（必需）：
  - 结构化课程
  - 七大模块红宝书
  - 系统结构化讲解课
  - 33大教育主题
- 学员评价（必需）：学员的具体反馈
- 购买历程（可选）：时间线、决策过程

**如果用户提供的信息不足，主动询问关键要素。**

### 第三步：查阅风格指南

**始终先阅读风格指南：**
```bash
读取 references/style-guide.md
```

重点关注：
- 语言风格特征
- Emoji使用规律
- 对应类型的结构模板
- 常用句式和高频词汇

### 第四步：参考优秀案例

根据用户需求的亮点，选择性阅读相关案例：

**上岸篇案例参考：**
```bash
读取 references/examples-shangang.md
```

选择相似类型案例（如逆袭类、第一名类、押中原题类等）

**反馈篇案例参考：**
```bash
读取 references/examples-feedback.md
```

选择相似产品类型案例（如课程反馈、讲义反馈等）

### 第五步：生成文案

#### 严格遵守以下原则：

**1. 结构规范**
- 上岸篇：标题 + 学员原话引用 + 成绩数据 + 蜗牛老师回应
- 反馈篇：标题 + 学员评价引用 + 蜗牛老师感恩回应

**2. 语言风格**
- 大量使用"真的"、"这么"、"特别"等强调词
- 保持口语化、有人味
- 感叹号密集使用传递热情
- 引号标注所有学员原话

**3. Emoji规范**
- 标题固定：上岸篇用 [鼓掌][烟花][烟花]
- 情感类：[爱心][爱心]、[拥抱]、[大哭]
- 成就类：[强][强]、[呲牙]、[跳跳]
- 鼓励类：[加油]、[愉快]

**4. 真实感营造**
- 具体数据：排名、分数、逆袭名次
- 时间锚点：5月10日、昨天、今天
- 细节刻画：激动一夜未睡、凌晨2.30
- 对话还原：保持学员口语化表达

**5. 价值传递**
- 自然植入：通过学员原话体现产品价值
- 对比衬托：学员自发对比其他课程（非蜗牛老师主动）
- 信任背书：学员推荐、上岸数据、专业认可

### 第六步：质量检查

生成后自查以下要点：

**内容检查：**
- [ ] 标题格式正确
- [ ] 学员原话用引号标注
- [ ] Emoji使用符合规范
- [ ] 有具体数据或细节
- [ ] 情感真诚，避免套路化

**风格检查：**
- [ ] 是否有"真的"、"特别"、"这么"等高频词
- [ ] 是否有感恩、共鸣、鼓励等情感表达
- [ ] 是否保持蜗牛老师谦虚、温暖的基调
- [ ] 是否避免过度商业化语言

**🎲 多样性检查（随机生成模式必查）：**
- [ ] 故事类型是否与上次不同？
- [ ] 地区城市是否与上次不同？
- [ ] 数字数据是否重新随机生成？
- [ ] 学员评价是否换了新的表达？
- [ ] 聊天时间和场景是否有变化？
- [ ] 学员昵称是否更换？
- [ ] 金句和案例是否避免重复？

### 情感词
感恩、感谢、开心、激动、幸福、温暖

### 共鸣词
理解、不容易、心酸、折腾、挺过来、熬到头

### 鼓励词
加油、努力、坚持、相信、期待、祝福

## 禁忌事项

### ❌ 绝对避免
- 过度商业化语言（限时优惠、立即下单）
- 夸大承诺（保证上岸、100%通过）
- 直接贬低同行
- 套路化模板感
- 缺乏具体数据和细节

### ✅ 正确方式
- 真诚分享学员故事
- 客观呈现学员评价
- 自然展示产品价值
- 保持谦逊感恩态度
- 用具体数据增强真实感

## 注意事项

1. **保持真实性**：所有数据、评价、时间线都应基于用户提供的真实信息
2. **尊重隐私**：如需提及学员姓名，询问用户是否需要化名
3. **灵活调整**：根据用户反馈随时调整文案风格和长度
4. **避免重复**：即使是相似类型，也要在细节和表达上有变化
5. **情感适度**：保持热情但不夸张，真诚但不做作

- emoji：🌸、🌻、🌈、⭐、🎀

**3. 对话自然性：**
- ✅ 学员分段发送（模拟真实聊天）
- ✅ 包含口语化表达（"哈哈哈"、"嗯嗯"）
- ✅ 蜗牛老师适时回应
- ✅ 总轮次6-10轮

**4. Emoji规范：**
- 只用蜗牛风格：[强][强]、[呲牙]、[拥抱]、[大哭]、[爱心]
- 禁用系统emoji：😊❤️等

**5. 内容要素：**
- 必须包含文案中引用的核心评价
- 添加自然的过渡对话
- 情绪递进：激动→感受→感谢→鼓励

## 🎨 自动化截图生成（New!）

本 Skill 现已支持**全自动生成高保真微信聊天截图**！

### 核心特性
- **真实感复刻**：1:1 复刻真实微信聊天界面（字体、气泡、布局）。
- **智能红框**：自动识别最正面的学员反馈，并添加**红色重点框**（模拟用户划重点习惯）。
- **无头像模式**：精确模拟左侧学员头像被裁剪的效果。
- **4K高清**：默认生成 4K 分辨率的高清图片。

### 使用方法

当您生成文案后，可以直接要求生成配图：

```bash
生成聊天记录图片
```

或者在生成文案时一并要求：

```bash
帮我写个上岸篇，并生成配套的聊天截图
```

系统会自动调用 `scripts/generate_wechat_screenshot.py`，使用当前生成的聊天记录内容，为您生成一张完美的配图。

**更新说明**：此功能于2026年1月添加，用于增强自由发挥模式的真实性和完整性。

## 🤖 每日自动推送功能 (Daily Auto-Push)

本技能现已支持 GitHub Actions 每日自动运行，每天早上 06:00 自动生成 3 条朋友圈文案（上岸篇、反馈篇、报名篇各一条）并推送到您的微信。

### 配置步骤

1. **获取 PushPlus Token**:
   - 访问 [PushPlus](http://www.pushplus.plus/) 注册并获取 Token。

2. **配置 GitHub Secrets**:
   在您的 GitHub 仓库设置中添加以下 Secrets：
   - `ANTHROPIC_AUTH_TOKEN`: 您的智谱/Claude API Key (Base URL 默认为 https://open.bigmodel.cn/api/anthropic)
   - `PUSHPLUS_TOKEN`: 您的 PushPlus Token

3. **启用 Workflow**:
   推送到 GitHub 后，Actions 会自动按照计划运行。您也可以在 "Actions" 标签页手动触发 `Woniu Daily Moments Push`。
