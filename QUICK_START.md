## ⚡ 快速命令

### 查看所有skill
```bash
ls ~/.claude/skills/
```

### 查看skill配置
```bash
cat ~/.claude/skills/skill-name/skill.config.json
```

### 启用/禁用skill
```bash
# 编辑配置文件
nano ~/.claude/skills/skill-name/skill.config.json

# 设置 "enabled": true 启用
# 设置 "enabled": false 禁用
```
