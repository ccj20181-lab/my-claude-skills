## 新需求分析

### 用户要求的六步工作流
1. **学习写作风格、规范**
2. **调用小红书 MCP 获取爆款笔记**
3. **采访用户想法、观点**
4. **列出提纲并确认**
5. **写作笔记**
6. **自我校验质量**

### 新增关键点
🆕 **第二步：小红书 MCP 集成**
- 工具：`mcp__xiaohongshu__search_feeds`
- 目的：获取同主题爆款笔记的选题角度和内容观点
- 策略：借鉴但不抄袭，获取灵感

🆕 **第四步：提纲确认**
- 在正式写作前，列出文章提纲
- 等待用户确认后再进入写作阶段
- 避免方向偏差，提高效率

### Prompt 重构策略

**核心原则：**
- 保持简洁性（官方最佳实践）
- 不引入复杂状态管理
- 使用自然的对话流程

**关键修改点：**
1. `## Workflow` 部分：从 6 步重构为 3 阶段 6 步
2. `## Rules & Constraints` 部分：新增小红书 MCP 相关规则
3. `## Input Format` 部分：明确需要提供"主题"和"标题"

### 小红书 MCP 集成细节

**调用时机：** Step 2（写作准备阶段）

**工具参数：**
```json
{
  "keyword": "用户提供的主题",
  "filters": {
    "sort_by": "最多点赞",
    "note_type": "不限"
  }
}
```

**信息提取重点：**
- 📌 爆款笔记的选题角度（切入视角）
- 💡 内容观点和论据
- 🎯 标题和开篇的吸引点
- 🔥 互动数据（点赞/收藏/评论）

**使用原则：**
- ✅ 借鉴选题角度和表达方式
- ✅ 吸收优质观点（需要验证）
- ❌ 绝不抄袭原文
- ❌ 不盲目追随爆款，保持专业深度

## 待解决的关键问题

### Q1: 如何优雅地集成小红书 MCP？
**方案 A（推荐）**：在 Workflow 中明确标注调用时机和参数
```markdown
2. **搜索小红书爆款**:
   - 使用 `mcp__xiaohongshu__search_feeds` 工具
   - 参数：keyword=主题, filters.sort_by="最多点赞"
   - 提取：选题角度、内容观点、标题技巧
   - 注意：借鉴角度，不抄袭内容
```

**方案 B**：创建单独的指导文件 `references/xiaohongshu-research.md`
- 优点：更详细的操作指南
- 缺点：增加文件复杂度

**决策**：采用方案 A，保持简洁性

### Q2: 提纲确认的具体格式？
**推荐格式：**
```markdown

主人，这个提纲符合您的预期吗？需要调整哪个部分喵？(๑•̀ㅂ•́)✧
```

### Q3: 如何保持 skill 的简洁性和高效性？
**简洁性保证：**
- ❌ 不引入状态变量（如 `current_phase`）
- ❌ 不创建额外的中间文件
- ✅ 使用自然对话推进流程
- ✅ 充分复用现有知识库
