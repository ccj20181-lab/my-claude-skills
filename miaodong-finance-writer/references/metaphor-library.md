# 比喻库:秒懂金融

## 使用原则

### 优质比喻三要素
- **熟悉度**: 80%读者能理解的生活场景
- **精准度**: 核心特征匹配度>80%
- **画面感**: 能在脑海中形成清晰场景

### 比喻质量评估
```
优质比喻 = 熟悉度(40%) + 精准度(40%) + 画面感(20%)
低于7分的比喻需要重新设计
```

### AI生成比喻质量检测
当需要现场生成比喻时,必须通过以下检测:
1. **熟悉度检测**: 是否有70%以上读者能理解这个场景?
2. **精准度检测**: 比喻的核心特征是否与原概念匹配?
3. **画面感检测**: 读者能否在脑海中形成清晰场景?
4. **误导性检测**: 是否存在严重简化导致误导?

**不通过检测的比喻必须重新设计,或直接使用定义解释。**

## 主题分类比喻库

### 主题: 股票市场
- **涨跌停** → "红绿灯": 涨到停是红灯,跌到停也是红灯,都表示"不能再走了"
- **换手率** → "二手房成交活跃度": 今天卖了明天又买,越频繁说明交易越活跃
- **市值** → "公司身价": 把整个公司卖掉能卖多少钱
- **市盈率** → "回本年数": 按现在的赚钱速度,买下公司需要几年回本
- **市净率** → "股价与净资产的比": 股价÷每股净资产
- **股息率** → "分红收益率": 每年分红÷股价,相当于存款利息
- **成交量** → "市场人气": 成交量越大,说明买卖的人越多,人气越旺

### 主题: 金融工具
- **期权** → "买保险": 支付期权费=买保险的保费,行权=出事了理赔,不行权=保险过期作废
- **可转债** → "变形金刚": 平时是债券(保本),股价涨了可以变身成股票
- **ETF** → "水果拼盘": 一篮子股票组合,买一个等于买一堆
- **期货** → "远期订单": 现在下单,未来交货,锁定价格
- **权证** → "优惠券": 持有券可以按约定价格买股票,过期作废
- **REITs** → "众筹买房": 大家凑钱买商业地产,收租金赚钱

### 主题: 宏观经济
- **央行** → "水龙头": 控制货币供应,拧松=放水,拧紧=收水
- **通货膨胀** → "烧饼涨价模型": 钱多了,烧饼数量不变,每个烧饼涨价
- **通货紧缩** → "烧饼降价模型": 钱少了,大家不消费,烧饼只能降价卖
- **降息/加息** → "水位调节": 降息=水位下降(资金成本低),加息=水位上升(资金成本高)
- **财政政策** → "政府花钱": 政府多花钱=刺激经济,少花钱=收紧
- **货币政策** → "央行调水龙头": 放水=刺激经济,收水=抑制经济
- **GDP** → "国家总收入": 一年内全社会生产的所有东西和服务总价值
- **CPI** → "物价变化率": 老百姓日常买东西的价格涨跌幅度

### 主题: 投资策略
- **做多** → "囤货商人": 低价买进,高价卖出,赌涨价
- **做空** → "空手套白狼": 借货卖出,等跌买回,赌跌价
- **对冲** → "两边下注": 一边买涨一边买跌,降低风险
- **分散投资** → "不要把鸡蛋放一个篮子": 买不同的资产,降低单一风险
- **定投** → "自动存钱罐": 每月固定买一点,平摊成本,降低择时风险
- **波段操作** → "低吸高抛": 跌了买,涨了卖,赚差价
- **价值投资** → "买好公司等长大": 找被低估的好公司,长期持有
- **套利** → "买低卖高": 利用不同市场的价格差赚钱

### 主题: 公司金融
- **IPO** → "上市敲钟": 第一次向公众卖股票
- **估值** → "给公司算身价": 看看公司值多少钱
- **融资** → "找钱": 向投资人或银行借钱或换股份
- **股权** → "公司所有权凭证": 有股权就是公司股东,有投票权和分红权
- **债券** → "借钱打欠条": 公司或政府向公众借钱,承诺付利息还本金
- **分红** → "公司给股东发红包": 赚了钱分给股东
- **回购** → "公司自己买自己的股票": 减少流通股,提升股价

### 主题: 银行与信贷
- **征信** → "信用身份证": 记录你借钱的信用历史
- **贷款利率** → "借钱的成本": 借钱要付的利息比例
- **存款准备金率** → "银行要存多少在央行": 银行收的存款要交一部分给央行
- **LPR** → "贷款基础利率": 银行给客户贷款的参考利率
- **房贷** → "买房借钱": 用房子做抵押,向银行借钱买房
- **信用卡** → "先花后还": 银行给你一个月无息贷款额度
- **逾期** → "借钱不还": 超过约定时间还没还钱
- **坏账** → "收不回来的账": 借钱的人还不上,银行亏了

### 主题: 交易机制
- **T+1** → "今天买明天卖": 今天买的股票,明天才能卖
- **T+0** → "当天买当天卖": 今天买的股票,今天就能卖
- **涨停板/跌停板** → "价格涨跌上限": 一天最多涨跌10%(科创板20%)
- **熔断** → "市场急刹车": 跌太多就暂停交易,让大家冷静一下
- **停牌** → "股票休息": 暂停交易,一般是有重大消息要公布
- **复牌** → "股票恢复交易": 消息公布后,重新开始交易

### 主题: 技术分析
- **K线** → "价格走势图": 红色=涨,绿色=跌,形状像蜡烛
- **均线** → "平均价格线": 5日均线=最近5天平均价格
- **MACD** → "动能指标": 看涨跌动能强弱
- **布林线** → "价格通道": 价格在这个通道里波动,触及上下轨可能反转
- **成交量** → "市场人气": 量涨价涨=真涨,量涨价跌=假涨

### 主题: 风险管理
- **止损** → "认赔离场": 亏到一定程度就卖出,防止亏更多
- **止盈** → "落袋为安": 赚到一定程度就卖出,把利润锁定
- **仓位管理** → "钱怎么分配": 不要满仓,留点现金应对波动
- **风险承受能力** → "能亏多少钱": 亏了多少不影响生活
- **杠杆** → "借钱放大收益": 用1万撬动10万交易,收益和风险都放大10倍

### 主题: 国际金融
- **汇率** → "钱换钱的比价": 1美元能换多少人民币
- **外汇储备** → "国家存的外国钱": 央行存了多少美元、欧元等
- **关税** → "大卖场入场费": 进口商品要交的税
- **贸易顺差** → "卖得多买得少": 出口>进口,赚外汇
- **贸易逆差** → "买得多卖得少": 进口>出口,花外汇
- **美联储** → "美国的央行": 控制美元供应,影响全球

### 主题: 其他常见概念
- **牛市** → "市场看涨,一路向上": 股价持续上涨
- **熊市** → "市场看跌,一路向下": 股价持续下跌
- **震荡市** → "上上下下像坐电梯": 涨涨跌跌,没有明确方向
- **白马股** → "业绩稳定的好公司": 蓝筹股,分红稳定
- **黑马股** → "突然爆发的冷门股": 平时不关注,突然大涨
- **垃圾股** → "业绩差的公司": 濒临退市,风险极大
- **妖股** → "暴涨暴跌的怪胎": 短时间暴涨,没有业绩支撑

## 比喻使用建议

### 优先级顺序
1. **御用比喻库**(8个经典): 已在多篇文章中使用,读者熟悉,优先使用
2. **主题分类比喻库**(50+): 按主题查找合适的比喻
3. **现场生成比喻**: 需通过质量检测,不达标则用定义解释

### 比喻组合技巧
- **类比链**: 从简单到复杂,用多个比喻层层递进
  - 示例: 央行→水龙头→放水收水→降息加息→资金成本
- **对比比喻**: 同时用正反两个比喻强化理解
  - 示例: 做多=囤货商人 vs 做空=空手套白狼
- **生活化数字**: 用具体数字让比喻更真实
  - 示例: 不是"价格上涨",而是"烧饼从1元涨到1.2元"

### 避免比喻误导
- 复杂概念优先用定义解释,比喻辅助理解
- 比喻后必须补充"但需要注意的是",说明比喻的局限性
- 示例: "期权就像买保险,但需要注意的是,保险是保风险,期权既保风险也博收益"
