# 系列知识库：秒懂金融小知识

本文档定义了“秒懂金融小知识”系列的内容结构和范例。

## 核心目标

系统性地解释一个具体的金融名词或概念，让读者“知其然，并知其所以然”。

## 标准内容结构 (推荐叙事流)

1.  **标题**：`秒懂金融小知识：[核心概念]`
2.  **开篇引入 (灵活处理)**:
    - **原则**: 开篇是“钩子”，目标是抓住读者眼球，绝不能千篇一律。
    - **强制要求**: **严禁**把“相信大家”作为万能开头。必须根据主题创造有吸引力的引入场景。
    - **生活类主题 (公积金/征信等)**: 可以从用户的“痛点”或常见误区开始，如：“每个月拿到工资条，看到被扣掉的公-积金是不是很肉疼？”
    - **专业类主题 (估值/做空等)**: 可以从一个常见的新闻场景或一个反常识的问题开始，如：“看新闻总说某公司估值几百亿，这价钱到底是怎么算出来的？”
3.  **核心讲解 (`是什么？`)**:
    - 用最通俗的语言给概念下定义。
4.  **(可选) 追本溯源 (讲个故事)**:
    - **使用场景**: 如果主题有著名的历史来源或创始人故事 (例如：查尔斯·庞兹的“庞氏骗局”、阿尔·卡彭的“洗钱”)，**强烈建议**在此处生动地讲述这个故事。
    - **作用**: 极大地增强文章的趣味性和记忆点，起到承上启下的作用，自然地过渡到“小明”的例子。
5.  **举个例子/打个比方**:
    - **必须**引入虚拟人物“小明”的故事，将抽象概念在“现代中国”的背景下进行场景化演绎。
6.  **深度剖析 (标题需灵活处理)**:
        - **原则**: 这是文章的核心价值部分，必须做到“深入浅出”。目标是从基础科普自然过渡到实战分析，主动揭示概念背后的常见误区、不同场景的应用标准和潜在“陷阱”。要善于在“小明”的基础案例上做“延伸”，引入新角色或新情景来对比说明复杂问题，让读者彻底理解。标题要根据内容灵活包装，而不是生硬地使用“你必须知道的几件事”。
    - **生活类主题**: 可以使用更具吸引力的标题，如 `你必须知道的“三大神技”` (公积金)，或者直接设问 `征信不好，会影响孩子上学吗？`
    - **专业类主题**: 可以使用更直接、更体现专业性的标题，如 `做空有哪些风险？` 或 `估值的两大主流派系`。
    - **内容模块**:
        - `和……有啥区别？` (对比分析)
        - `怎么操作/怎么办？` (实操步骤)
        - `有哪些风险/误区？` (风险提示)
        - `对我们有什么影响？` (关联性)
7.  **总结 (`总结一下`)**:
    - 精炼概括核心要点，并给出明确、可操作的建议。

### 结构A：对话式叙事结构（适合流程类概念）

**适用题材**：坐庄、IPO、主力套路、估值方法等有明确流程的概念

1. **对话式开篇**
   - "大家经常听到...咱们今天揭秘一下"
   - 像朋友聊天，拉近距离

2. **完整定义**
   - "所谓XX，是指..."
   - "还比较抽象对吧，我们举个例子"

3. **角色化叙事**
   - 引入具体角色（小黑、小白、小王等符合场景的角色名）
   - "第一步、第二步、第三步、第四步"
   - 每步讲清楚是什么、为什么

4. **数字具象化**
   - 用具体数字（60%、10元、20元、30元）

5. **收尾总结**
   - "这一整套操作就被称为..."
   - 确认角色身份
   - 首尾呼应

```
大家有接触股票的可能经常听到一个说法，就是庄家坐庄啦，

所谓坐庄，是指某些资金体量较大的机构或个人，通过低价买入
```

## 深度剖析的三级标准 (新增)

### L1 (基础) - **禁止使用**
- ❌ 列出要点，每个用一句话解释
- 示例: "做空有三个风险:1.亏损无上限 2.逼空风险 3.借券成本"
- **问题**: 列点式罗列，缺乏连贯性，没有在"小明"基础案例上延伸

### L2 (进阶) - **最低强制要求**
- ✅ 在小明案例上延伸(引入新角色/新情景)
- ✅ 用数字对比让概念具象化
- ✅ 揭示1-2个常见误区

**示例 (做空)**:
```
做空可不是稳赚不赔的买卖，风险大得很！

第一，亏损无上限。做多最多亏100%（股票跌到0），但做空的亏损理论上是无限的！
比如你10块做空一只股票，结果它涨到100块、1000块，你必须高价买回来还，亏多少
没有上限。

第二，逼空风险。就像游戏驿站事件，如果很多人同时做空一只股票，而股价不跌反涨，
做空者就会恐慌性买入平仓，反而推动股价更高，形成"逼空"，亏损会像滚雪球一样越
来越大。

第三，借券成本。做空要借股票，借股票要付利息。如果股价迟迟不跌，你每天都在付
利息，时间一长成本就很高了。
```

### L3 (高阶) - **鼓励达到**
- ✅ 包含真实历史案例
- ✅ 不同群体的不同处境对比
- ✅ 实操路径和门槛说明

**示例 (做空 - 历史案例)**:
```
案例一：浑水做空瑞幸咖啡。2020年，美国做空机构浑水发布报告，指控瑞幸咖啡财务
造假，伪造了数十亿元的销售额。消息一出，瑞幸股价暴跌80%以上，最后被迫退市。

案例二：索罗斯做空英镑。1992年，索罗斯判断英镑被严重高估，于是借入大量英镑卖出
换成马克。他的操作引发市场恐慌，大家纷纷抛售英镑，最终英国央行扛不住了，英镑
暴跌。索罗斯一战赚了10亿美元，被称为"打垮英格兰银行的人"。

案例三：游戏驿站散户逼空事件。2021年，对冲基金大量做空游戏驿站（GameStop）股票，
结果被美国散户在Reddit论坛上联合起来"逼空"——疯狂买入把股价从20美元拉到400
多美元。做空的机构被迫高价买回股票平仓，亏得倾家荡产。
```

**强制要求**: 深度剖析必须达到L2或L3级别，严禁L1级别列点罗列。

## 小知识系列叙事节奏模板 (新增)

### 标准叙事节奏

1. **钩子式开篇**(根据主题选择痛点型/悬念型/场景型)
2. **是什么？**(一句话定义+核心特征)
3. **(可选)追本溯源**(历史故事/创始人故事，如有明确来源)
4. **举个例子**(小明的第一层故事)
5. **深度剖析**(必须达到L2或L3):
   * A和B有啥区别？(对比分析)
   * 怎么操作/怎么办？(实操路径)
   * 为什么会这样？(底层逻辑)
   * 有哪些风险/误区？(陷阱揭示)
   * (可选)有哪些经典案例？(历史掌故)
6. **总结**(核心要点+行动建议)

### 过渡句要求

每个模块之间必须有承上启下的过渡，禁止生硬跳转:

**推荐过渡方式**:
- "问题来了，"
- "但不知道你好奇过没有，"
- "那……是咋回事？"
- "举个例子，"
- "我用烧饼来给大家算笔账，"

**禁止过渡方式**:
- "接下来我们聊聊XX"
- "下面介绍一下XX"

## 小明角色变体库 (新增)

### 打工人小明
- **适用场景**: 公积金、社保、个税、工资条
- **特征**: 每月领工资，关心到手收入
- **示例**: "小明每个月拿到工资条，看到被扣的公积金肉疼..."

### 创业者小明
- **适用场景**: IPO、估值、融资、股权
- **特征**: 开公司，想扩张，需要融资
- **示例**: "小明开了家烤鸭店，生意火爆，想开连锁..."

### 投机客小明
- **适用场景**: 期货、做空、做T、期权
- **特征**: 喜欢冒险，想赚快钱
- **示例**: "小明觉得猪肉要涨价，想先订一批货..."

### 普通投资者小明
- **适用场景**: 基金、股票、理财、定投
- **特征**: 想理财，但风险承受能力一般
- **示例**: "小明手里有点闲钱，想买点基金..."

### 消费者小明
- **适用场景**: 通货膨胀、关税、房价、消费
- **特征**: 关心物价，想省钱
- **示例**: "小明去超市买烧饼，发现涨价了..."

### 场景真实感检查清单
- [ ] 小明的动机是否合理?
- [ ] 数字是否符合实际(避免总是"1000万"、"10亿")?
- [ ] 情感反应是否真实(该肉疼时肉疼，该美滋滋时美滋滋)?

**小明故事同质化→尝试其他角色类型**
