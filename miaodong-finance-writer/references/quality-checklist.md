# 质量检查清单:秒懂金融文章发布前必查

本文档整合所有质量关卡,发布文章前必须逐项检查。

---

## 零、观点冲击力检查（第一道关卡）

**⚠️ 这是拦截大路货的核心关卡，不通过不得进入后续检查**

### 核心观点检测
- [ ] 是否有明确的核心观点？（一句话能概括）
- [ ] 核心观点是否具有冲击力？（对照下方5标准）
- [ ] 是否避免了10种大路货观点？
- [ ] 开篇前50字是否包含了"反常识"或"冲突"元素？

### 冲击力5标准检测
- [ ] **反直觉性**：是否能让读者产生"这不对吧？"的第一反应？
- [ ] **独家洞察**：是否有独特角度，不是人云亦云？
- [ ] **具体可感**：是否有具体数据/案例支撑？
- [ ] **冲突张力**：是否揭示矛盾、对立面或利益冲突？
- [ ] **行动导向**：不仅告诉"是什么"，更暗示"该怎么做"？

### 冲击力评分表（自评）
| 检测项 | 得分(1-10) | 说明 |
|--------|-----------|------|
| 反直觉性 | __/10 | 是否颠覆常识？ |
| 独家洞察 | __/10 | 是否有独特视角？ |
| 具体可感 | __/10 | 是否有数据/案例？ |
| 冲突张力 | __/10 | 是否揭示矛盾？ |
| 行动导向 | __/10 | 是否暗示行动？ |

**评分标准**：
- **总分≥40分**（平均8分/项） → 通过，进入后续检查
- **总分<40分** → 不通过，返回Step 4重新设计提纲

**⚠️ 警示：如果此关卡不通过，切勿进入后续检查！**

---

## 一、开篇检查(第一印象)

### 钩子类型检查
- [ ] 是否使用了真实钩子(痛点型/悬念型/场景型)?
- [ ] 是否避免了禁用模式("很多人问我"、"最近新闻")?
- [ ] 是否在3句话内建立了情感共鸣或好奇心?
- [ ] 开篇是否与当前经济环境体感一致?

### 禁用模式检测
- [ ] 无"最近新闻总是提到XX"
- [ ] 无"很多人问我XX是什么"
- [ ] 无"你有没有发现XX很火"
- [ ] 无"相信大家"开头的所有变体

**不通过→重新设计开篇**

---

## 二、结构完整性检查

### 小知识系列
- [ ] 是否有"是什么?"模块?(一句话定义+核心特征)
- [ ] 是否有"举个例子"(小明故事)?
- [ ] 是否有"深度剖析"模块?
- [ ] 深度剖析是否达到L2或L3级别?(严禁L1列点罗列)
- [ ] 是否有"总结一下"模块?

### 热点系列
- [ ] 是否有"最新消息"模块?
- [ ] 是否包含24-72小时内的最新信息?
- [ ] 是否标注了具体时间戳(截至X月X日)?
- [ ] 是否有"是什么?"、"为什么?"、"怎么办?"三个模块?

**不通过→补充缺失模块**

---

## 三、AI腔检测(风格纯净性)

### 开头AI腔
- [ ] 无"相信大家"、"话说回来"
- [ ] 无"最近...很火"、"新闻总是提到"
- [ ] 无"你有没有发现"

### 过渡AI腔
- [ ] 无"接下来我们聊聊"、"下面介绍一下"
- [ ] 无"值得注意的是"、"需要强调的是"
- [ ] 无"不仅如此"、"另外"

### 结尾AI腔
- [ ] 无"综上所述"、"总而言之"
- [ ] 无"希望这篇文章对您有帮助"
- [ ] 无"以上就是XX的全部内容"

### 句式AI腔
- [ ] 无大量"不仅...而且..."关联词堆砌
- [ ] 无"随着...的发展"、"在...背景下"
- [ ] 无"标志着"、"彰显着"、"体现了"
- [ ] 无"旨在"、"致力于"

### 语气AI腔
- [ ] 无"首先...其次...最后"的刻板结构
- [ ] 无"一方面...另一方面"的公文腔
- [ ] 使用了口语化表达(说白了、顾名思义、打个比方)
- [ ] 使用了情感词(肉疼、美滋滋、震惊、简直送钱)

**发现任何AI腔→必须修改**

---

## 四、叙事节奏检查(可读性)

### 过渡句检查
- [ ] 每个模块之间是否有承上启下的过渡句?
- [ ] 是否避免了生硬的概念跳跃?

### 推荐过渡方式
- 使用了"问题来了,"
- 使用了"但不知道你好奇过没有,"
- 使用了"那……是咋回事?"
- 使用了"举个例子,"
- 使用了"我用烧饼来给大家算笔账,"

### 禁止过渡方式
- [ ] 无"接下来我们聊聊XX"
- [ ] 无"下面介绍一下XX"

### 节奏检查
- [ ] 是否遵循"建立概念→举例说明→深入细节→总结"的节奏?
- [ ] 小明故事是否具体生动(数字合理、情感真实)?

**不通过→调整叙事节奏,增加过渡句**

---

## 五、深度剖析检查(内容价值)

### L2级别(最低要求)
- [ ] 是否在小明案例上延伸(引入新角色/新情景)?
- [ ] 是否用数字对比让概念具象化?
- [ ] 是否揭示了1-2个常见误区?

### L3级别(鼓励达到)
- [ ] 是否包含真实历史案例?
- [ ] 是否展示了不同群体的不同处境?
- [ ] 是否提供了实操路径和门槛说明?

### 深度剖析禁用模式
- [ ] 无L1级别的列点罗列(如"XX有三个风险:1.2.3.")
- [ ] 无概念堆砌(如"XX是...XX包括...XX特征有...")

**未达到L2→重新撰写深度剖析**

---

## 六、现实感校验(真实感)

### 时间敏感
- [ ] 热点文章是否标注了时间戳(截至X年X月X日)?
- [ ] 避免了"最近"这种模糊词

### 体感校准
- [ ] 物价话题:当前是通缩/通胀?百姓体感是否准确?
- [ ] 股市话题:当前是牛市/熊市/震荡市?
- [ ] 楼市话题:当前是涨/跌/横盘?

### 人群区分
- [ ] 展示了不同群体在同一事件下的不同处境
- [ ] 示例:烧饼涨价→卖家赚、买家亏、打工人难受

### 中国视角
- [ ] 热点文章是否展示了中国市场和读者的关联性?

**与现实体感冲突→调整表述**

---


## 八、语言风格检查(人话度)

### 术语控制
- [ ] 避免专业术语堆砌?
- [ ] 术语出现后立即用"人话"解释?

### 口语化表达
- [ ] 使用了"说白了"、"顾名思义"、"打个比方"
- [ ] 使用了"说白了就是"、"简单来说"

### 情感表达
- [ ] 使用了情感词(肉疼、美滋滋、震惊、简直送钱、亏得连底裤都不剩)
- [ ] 避免平淡表达(应该"送钱"的地方不能写"有利")

### 比喻质量
- [ ] 比喻是否生动(符合"熟悉度+精准度+画面感")?
- [ ] 比喻后是否补充了局限性说明?

**过于书面或平淡→调整语气**

---

## 九、小明故事检查(多样性)

### 角色多样性
- [ ] 小明的角色是否多样化(打工人/创业者/投机客/消费者)?

### 角色类型库
- [ ] 打工人小明:适用场景(公积金、社保、个税、工资条)
- [ ] 创业者小明:适用场景(IPO、估值、融资、股权)
- [ ] 投机客小明:适用场景(期货、做空、做T、期权)
- [ ] 普通投资者小明:适用场景(基金、股票、理财、定投)
- [ ] 消费者小明:适用场景(通货膨胀、关税、房价、消费)

### 场景真实感
- [ ] 小明的动机是否合理?
- [ ] 数字是否符合实际(避免总是"1000万"、"10亿")?
- [ ] 情感反应是否真实(该肉疼时肉疼,该美滋滋时美滋滋)?

**小明故事同质化→尝试其他角色类型**

---

## 十、最终检查(整体印象)

### 可复述性
- [ ] 读完是否能用一句话总结核心概念?
- [ ] 是否有至少一个"恍然大悟"的时刻?
- [ ] 是否能复述给朋友听?

### 价值感
- [ ] 是否有价值感(学到了知识/避坑技巧)?
- [ ] 是否有可操作的建议?

### 情感共鸣
- [ ] 是否产生了"秒懂"的满足感?
- [ ] 是否有继续阅读相关内容的兴趣?

**价值感不足→强化深度剖析或实操建议**

---

## 检查通过标准

✅ **所有项目均为"是"后方可发布。**

如有任何"否"项目,必须修改后重新检查。

---

## 快速检查版(发布前5分钟必过)

如果时间紧张,至少检查以下核心项目:

### 开篇(必须通过)
- [ ] 无禁用模式("很多人问我"、"最近新闻")
- [ ] 有真实钩子(痛点/悬念/场景)

### AI腔(零容忍)
- [ ] 无"综上所述"、"值得注意的是"
- [ ] 无"随着...的发展"、"标志着"

### 深度(最低L2)
- [ ] 无L1列点罗列
- [ ] 有延伸案例或误区揭示


### 现实感(必须准确)
- [ ] 与当前经济体感一致
- [ ] 热点文章有时间戳

**以上5项任一项不通过→不得发布**
