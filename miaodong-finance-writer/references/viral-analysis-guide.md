# 爆款分析指南

本文档是 Step 2「深度研究小红书爆款」的核心参考资料，定义了分析框架、输出模板和判断标准。

---

## 一、爆款分析六维框架

对每篇入选的 Top 笔记，从以下六个维度进行深度分析：

### 1. 📌 选题角度
**分析要点：**
- 切入视角是什么？（宏观/微观/个人/行业/对比）
- 差异化在哪里？（与同主题其他内容的区别）
- 共鸣点是什么？（击中了读者的什么痛点/痒点/爽点）
- 时效性如何？（是否抓住了热点窗口）

**提问清单：**
- 为什么选这个角度而不是其他角度？
- 这个角度能否复用到我的主题？

### 2. 💡 核心观点
**分析要点：**
- 主要论点是什么？（用一句话概括）
- 冲击力来源？（反常识/揭秘/预言/对比）
- 论据支撑？（数据/案例/权威引用/亲身经历）
- 论点可信度？（是否经得起推敲）

**警惕信号：**
- ⚠️ 无来源的惊人数据
- ⚠️ 过度简化的因果关系
- ⚠️ 情绪化大于理性分析

### 3. 🎯 标题技巧
**分析要点：**
- 标题类型？（见下方「标题公式库」）
- 钩子元素？（数字/疑问/悬念/利益/痛点）
- 字数和节奏？
- 关键词布局？

**标题公式库（财经类）：**
| 公式类型 | 结构 | 示例 |
|---------|------|------|
| 数字冲击 | [惊人数字] + [后果/影响] | "3万亿蒸发，普通人该怎么办？" |
| 反常识 | [常识] + 但其实 + [真相] | "都说买房保值，但其实..." |
| 揭秘型 | [权威/内幕] + 告诉你 + [秘密] | "银行不会告诉你的5个真相" |
| 对比型 | [A] vs [B]，[结论] | "月薪3万和月薪3千，差在哪？" |
| 痛点直击 | 为什么 + [痛点现象] + ？ | "为什么你总是存不下钱？" |
| 预言型 | [时间] + [预测] | "2025年，这3类人会更穷" |
| 利益驱动 | 学会这个 + [具体收益] | "学会这招，年省2万" |
| 身份共鸣 | [身份标签] + 必看/必知 | "30岁还没买房的人必看" |

### 4. 📐 内容结构
**分析要点：**
- 开篇钩子？（前3句如何抓住注意力）
- 叙事框架？（总分总/问题-分析-方案/故事-道理-行动）
- 信息密度？（干货比例 vs 废话比例）
- 节奏控制？（长短句交替/留白/转折）
- 结尾设计？（行动召唤/开放讨论/金句收尾）

**开篇类型识别：**
- 🎯 痛点直击型："你是不是也..."
- 🔮 悬念型："昨天发生了一件事..."
- 📊 数据震撼型："3万亿，没了。"
- 💬 对话型："朋友问我..."
- 🎭 场景还原型："早上打开账户，心凉了半截..."

### 5. 🗣️ 表达风格
**分析要点：**
- 人设定位？（专家/朋友/过来人/分析师）
- 语言特色？（口语化程度/专业术语使用/网络用语）
- 金句提炼？（有哪些值得摘录的表达）
- 情绪曲线？（如何调动读者情绪）

**金句类型：**
- 洞察型："xxx的本质是yyy"
- 对比型："xxx不是yyy，而是zzz"
- 行动型："与其xxx，不如yyy"
- 总结型："记住，xxx"

### 6. 💬 评论反馈
**分析要点：**
- 热门评论说什么？（赞同/质疑/补充/求助）
- 读者真实需求？（评论区暴露的痛点）
- 争议点在哪？（哪些观点引发讨论）
- 作者互动？（作者如何回复评论）

**评论挖掘价值：**
- ✅ 发现用户真实疑问（可作为文章要回答的问题）
- ✅ 识别争议点（可作为深度剖析的角度）
- ✅ 收集用户语言（可借鉴的表达方式）

## 二、单篇分析卡片模板

对每篇 Top 笔记，按以下格式输出分析：

```markdown
### 📝 笔记分析卡片 #[序号]

**基础信息**
- 标题：[原标题]
- 作者：[昵称]
- 互动数据：👍 [点赞] | ⭐ [收藏] | 💬 [评论]
- 发布时间：[日期]

**六维分析**

| 维度 | 分析结果 |
|------|---------|
| 📌 选题角度 | [一句话总结切入角度和差异化] |
| 💡 核心观点 | [主要论点 + 可信度评估：高/中/低] |
| 🎯 标题技巧 | [标题公式类型] + [钩子元素] |
| 📐 内容结构 | [开篇类型] + [叙事框架] |
| 🗣️ 表达风格 | [人设定位] + [1-2个金句摘录] |
| 💬 评论反馈 | [热评关键词] + [用户真实需求] |

**可借鉴清单** ✅
1. [具体可借鉴的元素1]
2. [具体可借鉴的元素2]

**警惕清单** ⚠️
1. [不应模仿的元素，附原因]
```

## 四、可借鉴 vs 不可借鉴判断标准

### ✅ 可借鉴

| 类型 | 说明 | 示例 |
|------|------|------|
| 选题角度 | 切入视角和问题框架 | "从普通人的钱包出发讲货币政策" |
| 标题公式 | 结构和钩子技巧 | 数字+后果的组合方式 |
| 开篇技巧 | 吸引注意力的方法 | 场景还原型开篇 |
| 表达方式 | 语言风格和节奏 | 短句+留白的节奏 |
| 结构框架 | 内容组织逻辑 | 痛点-分析-方案 |
| 金句句式 | 精彩表达的句式 | "xxx的本质是yyy" |

### ❌ 不可借鉴

| 类型 | 说明 | 原因 |
|------|------|------|
| 原文内容 | 具体的文字、段落 | 抄袭风险 |
| 未经验证的数据 | 无来源的惊人数字 | 可信度问题 |
| 过度情绪化表达 | 贩卖焦虑/愤怒 | 与"秒懂"专业定位不符 |
| 简化的因果关系 | 过度归因的论断 | 误导读者 |
| 标题党元素 | 夸大事实吸引点击 | 损害品牌信誉 |
| 低质量观点 | 缺乏深度的泛泛之谈 | 无价值 |

## 五、与后续步骤的衔接

### Step 2 → Step 3（访谈）
- 将「评论区洞察」中的用户疑问转化为访谈问题
- 针对「争议观点」设计深度追问

### Step 2 → Step 4（提纲）
- 将「可借鉴清单」中的应用建议融入提纲设计
- 参考「共性特征」确定文章基调

### Step 2 → Step 5（写作）
- 使用「标题公式库」优化标题
- 应用「开篇技巧」设计开头
- 借鉴「金句句式」增强表达力
- 根据「警惕清单」避免踩坑
